Connecting word guide

Keep the reason and result in the right order.
soUse before the result. Put a comma before so when joining two complete sentences: It rained, so we stayed inside.
becauseUse before the reason: We stayed inside because it rained. If because starts the sentence, use a comma after the reason: Because it rained, we stayed inside.
